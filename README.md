# Drugs annotations

A version of an existing drug annotation application used for a university thesis.
Includes a backend API and a web frontend.

## Запуск приложения

1. Launch file 

`scripts/launch-image.sh`

2. Приложение будет запущено на `0.0.0.0:8080/drug-annotations`

3. К api бэкенда можно попасть по `0.0.0.0:8080/drug-annotations/api`
